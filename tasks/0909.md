一般怎么操作（本地手动流程）

1. 加入 Apple Developer Program（$99/年），在开发者后台或 Xcode 里生成一个 "Developer ID Application" 证书（专门给"App Store 外分发"用的签名证书，跟 App Store 上架用的证书不是同一种）。
2. 用这个证书重新签名（把项目里现在的 CODE_SIGN_IDENTITY="-" 换成这个证书的身份）：
   codesign --deep --force --options runtime --sign "Developer ID Application: 你的名字 (TEAMID)" ClipPower.app
   注意 --options runtime（开启 Hardened Runtime）是苹果公证的硬性要求，没开会被拒。
3. 打包成 dmg（跟现在 release.yml 里的步骤一样）。
4. 提交公证，现在苹果统一用 notarytool（老的 altool 已经淘汰）：
   xcrun notarytool submit ClipPower.dmg --apple-id 你的AppleID --team-id TEAMID --password app专用密码 --wait
   （--wait 会一直等到苹果扫完给结果，通常几分钟；密码不是登录密码，是苹果账号后台生成的"应用专用密码"）
5. 通过后把票据钉到 dmg 上：
   xcrun stapler staple ClipPower.dmg
6. 分发这个 dmg，用户双击打开不会再有任何 Gatekeeper 警告。

放进现有 CI 流程（.github/workflows/release.yml）大致要加什么

- 把 Developer ID 证书（.p12 文件，base64 编码）和密码存成 GitHub Secrets，跑的时候导入一个临时 keychain
- codesign 时把身份换成这个证书
- 用 App Store Connect 的 API Key（issuer ID + key ID + .p8 私钥，也存成 Secrets）代替 Apple ID 密码调 notarytool submit（CI 里免密码更安全、更稳定）
- 通过后 stapler staple 再打包发布
